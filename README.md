# Kalang Kabut

A work-in-progress first-person walking demo set in a haze-covered Indonesian roadside settlement. Low-poly buildings, low-resolution photographic textures, made-up advertising, foliage cutouts and overhead powerlines.

## Controls

- WASD / arrow keys: walk
- Mouse: look
- Shift: run
- Space: jump
- Esc: pause and change haze, resolution, sound or walking motion

Desktop browser with WebGL required. Click Walk to capture the mouse. This demo is an environment study without objectives or delivery mechanics.

## GitHub Pages

Serve the main branch from the repository root through GitHub Pages. `index.html` is the entry point; all dependencies and textures are included locally. The `.nojekyll` file enables plain static hosting.

## Local preview

Serve this directory using any static HTTP server. Opening this multi-file edition directly through file:// will not load browser ES modules; use HTTP or the separate standalone HTML edition.
